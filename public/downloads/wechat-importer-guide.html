已安装旧版？请更新到 1.0.1

本次修复“只能从对应的宇宙放映后台接收文章”的误报。

  1. 下载下方新版 ZIP，解压后覆盖原插件文件夹。
  2. 打开浏览器扩展管理页，点本插件的重新加载，确认版本显示 1.0.1。
  3. 刷新后台，回到公众号原文重新点插件导入。

无需卸载插件，也不用重新创建活动。只刷新网站不会更新本机插件。

把公众号文章带进活动

在电脑 Chrome 或 Edge 中安装一次，以后点击插件就能把标题和图文带入后台。

下载导入插件 1.0.1 ZIP

首次安装

  1. 下载 ZIP，解压到固定文件夹。之后请保留这个文件夹。
  2. 打开扩展管理页：Chrome 地址栏输入 chrome://extensions；Edge 输入 edge://extensions。
  3. 打开开发者模式，点加载已解压的扩展程序，选择包含 manifest.json 的文件夹。
  4. 在浏览器工具栏的扩展菜单中，把宇宙放映 · 公众号导入固定到工具栏。刷新已打开的后台页面。

以后这样导入

  1. 在同一个浏览器打开公众号文章，等待正文显示。如果微信要求验证，请先完成验证。
  2. 点工具栏插件，再点导入到宇宙放映。
  3. 后台自动填好标题、原文链接和图文。未登录时，先使用管理员账号登录。
  4. 选择所属活动，点转换并保存草稿。保存图片后可进入编辑器核对、调整和发布。

在微信内置窗口里看到文章时，先复制链接到安装了插件的 Chrome 或 Edge。后台已有未保存的编辑内容时，请先保存，再回到文章重新导入。

常见情况

没有读取到正文：先确认文章已正常显示；插件不会代做微信验证。仍失败时可用后台的“粘贴图文”。

后台没有收到文章：检查插件是否启用、是否在同一浏览器安装，刷新后台后重试。

图片转存失败：文字带入后台后，图片仍需要联网保存；请稍后重试。单篇最多 40 张图片，视频、小程序保留原文入口。

暂存与权限：文章仅在本机插件暂存，24 小时后失效，保存草稿后移除。插件不读取后台密码或登录凭据；接收图文不会直接发布。

安装与更新：这是本网站的本地安装版，尚未上架扩展商店。更新时替换原文件夹内容，在扩展管理页点“重新加载”。
